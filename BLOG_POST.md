## About the Project

AntiqueAuction is a frontend-only marketplace for antiques, vintage items and collectibles. It connects collectors and enthusiasts with historical pieces that have documented stories — origin, era, provenance, condition and restoration history. The platform includes 12 curated lots across furniture, art, jewelry/timepieces and rare books.

## Features Built

- Home page with featured antiques, categories, curator's pick and auction highlights
- Antique listing with search and filters for era, region, category, condition, price, authentication and live status
- Antique detail pages with provenance timeline, condition report, restoration history and image gallery
- Simulated expert valuation with estimated price range, confidence score and expert notes
- Live bidding system with countdowns, bid increments, quick bids and bid history
- Authenticity verification with certificate register, lookup by certificate number and printable certificates
- Collector dashboard — watchlist, bidding history, leading bids and won items
- Seller dashboard — list, edit, delete and mark antiques as sold; track sales and export CSV reports
- Login/Register with demo accounts and a guest-to-sign-in flow
- Bonus: virtual gallery, curator's recommendations, dark mode, CSV/print exports and responsive mobile navigation

## Technologies Used

HTML5, CSS3, JavaScript (ES6+), Google Fonts, Font Awesome and browser localStorage. No database and no framework were used — all antiques, bids, users, valuations and certificates are stored in JavaScript arrays and objects.

## What I Learned

This project helped me practise semantic HTML, responsive CSS, vanilla JavaScript state management, hash-based routing, localStorage persistence, filters and sorting, form validation and client-side document generation. The most challenging part was keeping bid data consistent across the detail page, live room and both dashboards — I solved it by centralising state updates and re-rendering the active view after each change.
