Project Description:
AntiqueAuction is a frontend-only antique auction platform built for the Free Web Development Internship Online task. It connects collectors and antique lovers with vintage pieces that have documented history, provenance, condition reports and restoration records. The project includes 12 curated antiques across furniture, art, jewelry and rare books, with a complete bidding and collection management workflow.

Features Implemented:
Home page with featured antiques, categories, curator's pick and auction highlights.
Antique listing with search and filters for era, region, category, condition, price and authentication.
Antique detail pages with provenance timeline, condition report, restoration history and image gallery.
Expert valuation (simulated) with estimated price range, confidence score and expert notes.
Live bidding system with countdowns, bid increments, quick bids and bid history.
Authenticity verification with certificate register, certificate number lookup and printable certificates.
Collector dashboard with watchlist, bidding history, leading bids and won items.
Seller dashboard with inventory management, sales tracking and CSV export.
Login and Register with demo accounts.
Bonus features: virtual gallery, curator's recommendations, dark mode and responsive mobile navigation.

Technologies Used:
HTML5, CSS3, JavaScript, Google Fonts, Font Awesome and localStorage. No database and no framework were used. All antiques, bids, users, valuations and certificates are stored in JavaScript arrays and objects.

Learning Outcome:
This project helped me learn semantic HTML, responsive CSS, vanilla JavaScript state management, local storage, filtering and sorting, form validation, client-side routing and print-friendly document generation.
